# Interview Prep Knowledge Base

> A structured, from-scratch study system built around your resume (Ruby on Rails, React, React Native/Expo, TypeScript, Node.js, Django and everything else on it) for 1-year+ full-stack interviews: 182 Markdown files, about 81,000 lines, and more than 4,100 interview questions with model answers.

## Start here

1. **[Study roadmap](00-start-here/01-study-roadmap.md):** priorities, role tracks, and 6-week, 2-week and 3-day plans.
2. **[Resume-to-topics map](00-start-here/02-resume-to-topics-map.md):** every resume line, where to study it, and the questions it invites.
3. **[Interview formats](00-start-here/03-interview-formats.md):** what each round tests and how to prepare for it.
4. **[Last-minute revision](00-start-here/04-last-minute-revision.md):** the night-before sheet.

Then answer the `> **Fill in:**` prompts, starting with [your projects](17-projects-deep-dive/01-crystalcommerce.md) and the [resume line-by-line defense](18-behavioral-and-hr/06-resume-line-by-line-defense.md). They ask for details only you know (real numbers, decisions, reasons), and your project answers depend on them. Search the folder for `Fill in:` to find them all.

## How every topic file works

| Section | Use it to |
|---|---|
| `Quick revision` | Re-read in the last 10 minutes before an interview |
| Numbered concept sections | Learn the topic from zero to interview depth, with code |
| `Common pitfalls` | Avoid the mistakes interviewers probe for |
| `How to talk about this in an interview` | Connect the topic to your real experience |
| `Interview questions` | Self-test with model answers and the likely follow-up |

`99-interview-questions.md` files are rapid-fire banks for a whole folder: cover each answer, say yours out loud, then check.

## Tiers

| Tier | Meaning |
|---|---|
| `T1` | Know cold: explain from memory, write the code, handle follow-ups |
| `T2` | Working knowledge: explain concepts and trade-offs, read code confidently |
| `T3` | Essentials: define the key terms and describe your real exposure honestly |

## Conventions

- DSA and OOP fundamentals use **C++17**; every other file uses its own stack's language (Ruby, JavaScript, TypeScript, Python, SQL, C#, Java).
- Version-specific features name the version that introduced them. Fast-moving tools (Expo, Next.js, TanStack Start, oRPC, Drizzle) are flagged so you check details against their official docs.
- Diagrams use Mermaid, which renders on GitHub and in Obsidian, and in VS Code with a Mermaid preview extension.
